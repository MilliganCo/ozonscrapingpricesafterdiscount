# Ozon Scraping Prices After Discount

## О проекте

`Ozon Scraping Prices After Discount` — скриптовый проект для выборочной проверки карточек Ozon и извлечения цен после скидок непосредственно со страницы товара. Судя по структуре, это исследовательский scraper/utility-проект для проверки витринных цен и доступности товаров.

## Что делает скрипт

- принимает список товарных URL;
- извлекает `product_id` из ссылок;
- проверяет наличие товара на странице;
- пытается достать текущую и исходную цену;
- работает через Playwright и сохраняет результаты во внешние файлы.

## Стек и структура

- Python
- Playwright
- ключевой файл: `ozon_webaspects_scraper_old_version.py`

## Запуск

Проект рассчитан на запуск как обычный Python-скрипт после установки зависимостей браузерного стека.

Пример:

```bash
python ozon_webaspects_scraper_old_version.py
```

## Статус

`WIP / research utility`. Это не полноценный сервис, а прикладной исследовательский инструмент для ручной или полуавтоматической проверки цен на страницах Ozon.
